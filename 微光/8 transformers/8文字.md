# 一、Transformer 特点、解决问题与缺点
## 特点：
1. 纯注意力机制，无 RNN/CNN 循环或卷积结构；  
2. 并行计算能力强；
3. 长距离依赖捕捉效果更优。  
## 原论文对应位置：
1. Introduction、3 Attention Mechanism；  
3.2 Scaled Dot-Product Attention；  
3.5 Multi-Head Attention。  
## 解决问题：
1. 解决 RNN 串行计算导致的训练速度慢问题；
2. 解决 RNN 长距离梯度消失或衰减问题；
3. 解决 CNN 捕捉长依赖需堆叠多卷积层的低效问题。
## 原论文对应位置：
1. Introduction（三点均对应）。
## 缺点：
1. 计算复杂度高（公式为 O (n²d)，n 为序列长度，d 为特征维度）；
2. 长序列处理时计算和显存成本高；  
3. 对低频词的鲁棒性较差。
## 原论文对应位置：
5.4 Limitations（三点均对应）。
# 二、Layer Norm vs Batch Norm
归一化维度：Layer Norm（层归一化）是对单样本内的特征维度归一化（即对每个样本，归一化其所有特征）；Batch Norm（批归一化）是对批次内的样本维度归一化（即对每个特征，归一化批次内所有样本）。
适用场景：Layer Norm 适用于 Transformer 的 Encoder/Decoder 层内；Batch Norm 更适用于 CNN、RNN 等非序列建模主流场景。
核心差异（“恩怨”）：1. Layer Norm 不依赖批次大小，适合小批量和序列任务；2. Batch Norm 受批次影响大，在序列任务中易不稳定；3. Transformer 采用 Layer Norm，正是为解决训练中的梯度稳定问题。原论文对应位置：3.1 Normalization。
# 三、位置编码（Positional Encoding）
定义：为输入序列的每个 token 添加位置信息，弥补纯注意力机制无顺序感知的缺陷（注意力本身 “无序”，需显式注入位置信息）。
Transformer 使用的位置编码：正弦 / 余弦固定位置编码（非可学习），公式为：PE (pos,2i) = sin (pos/10000^(2i/d_model))，PE (pos,2i+1) = cos (pos/10000^(2i/d_model))（其中 pos 是 token 在序列中的位置，i 是特征维度索引，d_model 是 embedding 维度）。
设计优势：1. 可泛化到训练时未见过的更长序列；2. 计算高效，无额外可学习参数；3. 能通过三角函数关系捕捉 token 间的相对位置距离。
原论文对应位置：3.5 Positional Encoding。
# 四、Encoder & Decoder 架构解析
1. 模块结构
Encoder（原论文堆叠 6 层）：输入 Embedding + 位置编码 → 多头注意力（Multi-Head Attention） → 残差连接 + Layer Norm → 前馈网络（FFN） → 残差连接 + Layer Norm。
Decoder（原论文堆叠 6 层）：目标序列 Embedding + 位置编码 → 掩码多头注意力（Masked Multi-Head Attention，屏蔽未来 token） → 残差连接 + Layer Norm → 编码器 - 解码器注意力（Encoder-Decoder Attention，Q 来自 Decoder，K/V 来自 Encoder） → 残差连接 + Layer Norm → 前馈网络（FFN） → 残差连接 + Layer Norm。
2. 数据流动
Encoder：输入文本→tokenize 处理→生成 embedding 并叠加位置编码→逐层经过多头注意力和前馈网络→最终输出 Encoder 特征（供 Decoder 使用）。
Decoder：目标文本→tokenize 处理→生成 embedding 并叠加位置编码→先通过掩码注意力（防止 “偷看” 未来 token）→再用 Encoder 输出做交叉注意力→经过前馈网络→输出每个位置的 token 预测概率。
原论文对应位置：3 Model Architecture、图 1（The Transformer - Model Architecture）。
# 五、注意力机制核心问题
K、Q、V 定义与变化：K（Key，键）是 token 的 “特征标识”，Q（Query，查询）是当前 token 的 “查询需求”，V（Value，值）是 token 的 “特征内容”；三者均由输入通过 3 个不同的线性层（W_Q、W_K、W_V）映射得到，维度均为 d_k。
Q×K^T 的数学内涵：计算 Q 与每个 K 的相似度（内积运算），结果即为 “注意力分数”，用于表示每个 K 对当前 Q 的重要性程度。
Scaled Dot-Product Attention vs Additive Attention：Scaled Dot-Product Attention 通过公式 Attention (Q,K,V) = softmax ((QK^T)/√d_k) V 计算，优势是计算速度快、显存占用低，适合高维数据；Additive Attention（如 Bahdanau 注意力）通过 MLP 将 Q/K 映射到同一维度再算相似度，低维数据表现优但复杂度高。
自注意力 “自” 的体现：Q、K、V 来自同一输入序列（如 Encoder 中，用自身序列的 token 互相查询重要性）；如此设计是为让序列内 token 间建立依赖关系（例如 “他” 指代前文 “小明”）。
原论文对应位置：3 Attention Mechanism、3.2 Scaled Dot-Product Attention。
# 六、可学习参数分析
基础注意力机制：有可学习参数，即映射 Q、K、V 的 3 个线性层权重（W_Q、W_K、W_V）。
多头注意力：除每个注意力头各自的 W_Q^i、W_K^i、W_V^i（i 为头的索引）外，还包含将多个头输出拼接后进行线性变换的 W_O，这些均为可学习参数。
期望学到的内容：W_Q 和 W_K 学习 “如何计算 token 间的相关性”，W_V 学习 “如何提取 token 的关键特征”，W_O 学习 “如何融合多个注意力头的信息”。
原论文对应位置：3.2 Scaled Dot-Product Attention、3.3 Multi-Head Attention。
# 七、数据流动全解析（文本输入→输出）
输入阶段：文本→tokenize（如 WordPiece）→得到长度为 n 的 token 序列。
Embedding 阶段：token→通过嵌入层→生成 n×d_model 维度的嵌入矩阵（d_model 为 embedding 维度）。
位置编码阶段：为嵌入矩阵叠加同维度（n×d_model）的位置编码→得到 Encoder/Decoder 的输入矩阵。
Encoder 处理：输入矩阵逐层经过多头注意力（Q=K=V）→残差连接 + Layer Norm→前馈网络→残差连接 + Layer Norm→输出 Encoder 特征（n×d_model）。
Decoder 处理：目标 token 的 Embedding + 位置编码→掩码多头注意力（Q=K=V，屏蔽未来 token）→残差连接 + Layer Norm→编码器 - 解码器注意力（Q=Decoder 输出，K/V=Encoder 特征）→残差连接 + Layer Norm→前馈网络→残差连接 + Layer Norm→输出 logits（n×vocab_size，vocab_size 为词表大小）。
输出阶段：logits→softmax 计算概率分布→取概率最大的 token→生成最终文本。
原论文对应位置：3 Model Architecture、图 1。
# 八、BLEU 评估指标
定义：BLEU（Bilingual Evaluation Understudy，双语评估研究），是衡量机器翻译输出与人类参考译文相似度的指标。
在 NLP 中的角色：作为机器翻译、文本生成任务的主流评估指标，核心是计算 “n-gram 精确率”（如 1-gram、2-gram 的匹配程度），并引入 “短句惩罚因子”（避免模型输出过短的句子以提高表面精确率）。
原论文对应位置：5.1 Evaluation Metrics。
